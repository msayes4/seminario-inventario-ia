# Sistema Web Inteligente para la Gestión de Inventarios y Pronóstico de Stock mediante Inteligencia Artificial

## Descripción

Sistema web desarrollado para facilitar la gestión de inventarios de pequeñas y medianas empresas. Permite administrar productos, controlar movimientos de existencias, consultar reportes y generar pronósticos de stock.

## Funcionalidades principales

- Inicio y cierre de sesión.
- Gestión de usuarios y control de acceso por roles.
- Registro, consulta y edición de productos.
- Control de entradas, salidas y ajustes de inventario.
- Pronóstico de stock basado en el historial de movimientos.
- Consulta de reportes de inventario.

## Tecnologías utilizadas

- PHP
- MySQL
- Python
- Pandas
- Scikit-learn
- HTML y CSS
- Docker

## Requisitos

- PHP con la extensión MySQLi, si se ejecuta directamente.
- MySQL 8 o compatible.
- Python y las dependencias de requirements.txt, cuando corresponda.
- Docker, para ejecutar la imagen proporcionada.

## Instalación

1. Descarga o clona el repositorio.
2. Configura la conexión a la base de datos mediante variables de entorno.
3. Crea la base de datos e importa database/inventario_publico.sql.
4. Crea un usuario administrador propio mediante un procedimiento seguro.
5. Inicia la aplicación siguiendo las instrucciones de ejecución del proyecto.

No publiques contraseñas, claves de aplicación ni credenciales personales en el repositorio. No utilices cuentas de demostración con contraseñas conocidas en un entorno público.

## Ejecución local

La aplicación puede ejecutarse mediante Docker o mediante un servidor PHP configurado con acceso a una base de datos compatible.

## Proyecto académico

Desarrollado como proyecto académico sobre la gestión de inventarios y el pronóstico de stock mediante inteligencia artificial.
